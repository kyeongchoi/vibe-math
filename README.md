# 바이브 수학 사이트 — 구조와 권 추가 방법

중학교 1·2·3학년 × 상·하 = 6권으로 확장할 수 있도록 **시리즈 허브 + 권별 폴더 + 공통 자산** 구조로 되어 있습니다.
`website/` 폴더 전체를 그대로 올리면(GitHub Pages, Netlify 등) 동작하고, 폴더를 열어 `index.html`을 더블클릭해도(file://) 동작합니다.

```
website/
├── index.html          시리즈 허브 — 6권을 학년별로 보여 주고, 공개된 권으로 연결
├── assets/
│   ├── site.css        공통 스타일 (허브 + 모든 권 페이지)
│   ├── logo.png · favicon.png · apple-touch-icon.png   로고(머리글 표시)·브라우저 탭·홈 화면 아이콘 — 원본 logo.png 에서 생성
│   ├── series.js       ★ 시리즈 설정: 6권의 목록·상태·편 구성·저자·이메일
│   └── volume.js       권 페이지 공통 스크립트 (통계·단원 지도·갤러리·권 전환)
├── g1-1/               중학교 1학년 상  (공개)
│   ├── index.html      ← 이 권의 앱 활동 데이터만 들어 있는 얇은 페이지
│   └── img/            ← 활동 화면 캡처 (그림 1.1 → 1-1.jpg)
├── g1-2/  g2-1/  g2-2/  g3-1/  g3-2/      ← 준비되는 권부터 같은 구조로 추가
└── _template/
    └── index.html      새 권을 만들 때 복사해서 쓰는 뼈대
```

폴더 이름 규칙: `g{학년}-{1=상, 2=하}` → g1-1(1학년 상), g1-2(1학년 하), g2-1, g2-2, g3-1, g3-2

## 새 권(예: 1학년 하 = g1-2)을 공개하는 순서

1. **폴더 만들기** — `_template/` 를 복사해서 `g1-2/` 로 이름을 바꿉니다. 그 안에 `img/` 폴더를 만들고 활동 화면 캡처를 넣습니다.
   - 파일 이름은 그림 번호를 따릅니다: 그림 1.1 → `1-1.jpg`, 그림 3.12 → `3-12.jpg` (세로 360×511 비율 권장)
2. **`g1-2/index.html` 고치기** — 머리 부분의 안내 주석대로 세 곳만 바꿉니다.
   - `<html data-volume="gX-Y">` → `data-volume="g1-2"`
   - `<title>` 과 `<meta name="description">` 내용
   - 맨 아래 `<script id="vm-data" type="application/json">[ ]</script>` 의 `[ ]` 안에 앱 활동 데이터를 넣습니다.
3. **`assets/series.js` 고치기** — `g1-2` 항목을 아래처럼 바꿉니다.
   ```js
   { id: 'g1-2', grade: 1, vol: '하', status: 'live',          // planned → live
     parts: ['기본 도형', '평면도형과 입체도형', '자료의 정리와 해석'],   // 실제 편 이름
     apps: 180, published: '2027-03-01',                       // 앱 수, 공개일
     fan: [ { id: '1.3', name: '…' }, { id: '2.7', name: '…' }, { id: '4.2', name: '…' } ] },  // 상단에 펼칠 앱 3개
   ```
4. 끝. 허브의 카드가 "공개"로 바뀌고 통계·큰 버튼·권 전환 메뉴에 자동으로 반영됩니다.

제목, 저자, 푸터, 편(Ⅰ·Ⅱ·Ⅲ…) 버튼과 단원 지도는 `series.js` 의 정보와 데이터에서 자동으로 만들어지므로 따로 손볼 곳이 없습니다.
편이 4개인 권도 그대로 동작합니다(네 번째 편 색 `--p4` 가 준비되어 있음).

## 앱 활동 데이터 형식 (`vm-data`)

한 활동 = 객체 하나. 책에 실린 순서대로 배열에 넣습니다.

```json
{
  "id": "1.1",                       // 그림 번호 (장.번호) — 화면 캡처 파일 이름과 연결
  "part": "Ⅰ. 수와 연산",            // 편: "로마숫자. 이름" 형식 (편 버튼·단원 지도가 여기서 만들어짐)
  "chapter": "1. 소인수분해",         // 장
  "section": "소인수분해",            // 소단원
  "name": "직사각형 배열탐험",         // 앱 이름
  "featured": false,                 // 책의 ★ 추천 표시 여부
  "type": "조작 · 시각 실험",          // 활동 유형(4가지): 조작 · 시각 실험 · 개념 판별 · 퀴즈 · 수리소 (오류 진단) · 게임 · 챌린지 — 갤러리의 "활동 유형" 선택 상자로 거를 수 있음
  "description": "…입니다.",          // 설명문
  "book_page": 3,                    // 책 쪽수
  "app_url": "https://…"             // 앱 주소 (비워 두면 카드가 링크 없이 표시됨)
}
```

## 활동 유형 필터

갤러리의 필터 줄에 **활동 유형** 선택 상자(모든 활동 유형 / 조작 · 시각 실험 / 개념 판별 · 퀴즈 / 수리소 (오류 진단) / 게임 · 챌린지)가 있습니다.
각 활동의 `type` 값이 그대로 선택 항목이 되며, 항목 순서와 색(카드의 유형 점: 파랑·초록·주황·보라)은 `assets/volume.js` 의 `TYPE_ORDER` 와
`assets/site.css` 의 `--t1`~`--t4` 로 정해집니다. 데이터에 새 유형 값을 쓰면 선택 상자 뒤에 자동으로 추가됩니다.

## 최근에 연 활동 기억 (브라우저 localStorage)

- 권 페이지에서 활동 카드를 누르면 앱이 새 탭에서 열리고, 이 탭에서는 그 카드가 "마지막으로 연 활동" 테두리와 함께 화면 가운데로 옵니다. 이전에 열었던 다른 카드에는 "최근 연 활동" 표가 붙습니다.
- 갤러리 바로 위 "↩ 최근에 연 활동" 줄에 최근 것부터 **최대 8개**가 작은 카드로 가로로 나열됩니다(넘치면 옆으로 스크롤). 작은 카드를 누르면 갤러리의 그 카드로 이동해 화면 가운데에 보여 주고(필터에 가려져 있으면 필터를 풀고 이동), 카드 안의 "앱 열기 ↗"는 앱을 바로 엽니다. × 로 하나씩, "모두 지우기"로 전부 지울 수 있습니다.
- 같은 브라우저로 다시 들어오면(허브의 "이어서 보기" 링크, 즐겨찾기, 주소 입력) 이 줄을 화면 가운데에 바로 보여 줍니다. 새로고침·뒤로가기는 브라우저가 보던 위치를 되돌리므로 그대로 둡니다.
- 최대 개수는 `assets/volume.js` 맨 위 쪽의 `RECENT_MAX = 8` 로 바꿉니다.
- 저장 위치: 각 기기·브라우저의 localStorage, 키 `vm:recent:{권 id}` (예: `vm:recent:g1-1`), 값 `[{"id":"5.12","name":"…","t":시각}, …]` (최근 것이 앞). 서버로는 아무것도 보내지 않습니다.

## 저자·이메일 바꾸기

`assets/series.js` 의 `VM_SITE` (author, email) 한 곳만 고치면 모든 페이지의 푸터("저자: …")에 반영됩니다. (저자 이름은 푸터에만 표시하고 위쪽 제목 줄에는 넣지 않습니다.)
(검색엔진용 `<meta name="author">` 는 각 페이지 머리에 따로 있으니 함께 바꿔 주세요.)
